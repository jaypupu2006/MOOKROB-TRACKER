# แผนที่จริงในหน้า /map ด้วย Leaflet

เปลี่ยนแผนที่จำลอง (ตาราง grid + หมุด CSS) ในหน้า `/map` เป็นแผนที่จริงจาก OpenStreetMap ผ่าน Leaflet / react-leaflet โดยไม่ต้องใช้ API key และใช้ข้อมูลร้านจริงจากฐานข้อมูลเดิม (31 ร้าน) พร้อมสถานะและเวลาอัปเดตล่าสุด

## สิ่งที่จะได้

- แผนที่เลื่อน/ซูมได้จริง มี attribution ของ OpenStreetMap
- หมุด "คุณอยู่ที่นี่" สีน้ำเงิน + วงรัศมี ใช้ตำแหน่ง GPS ที่แอปเก็บไว้แล้ว ถ้าไม่อนุญาตจะ fallback ไปใจกลางกรุงเทพฯ [13.7563, 100.5018] ซูม 13
- ปุ่มลอย "ตำแหน่งของฉัน" มุมขวาล่างของแผนที่ กดแล้วขอ GPS ใหม่และเลื่อนแผนที่กลับมาที่ตัวเอง
- หมุดร้านเป็น SVG pin ตามสถานะ: เขียว (มีหมูกรอบ), เหลือง (เหลือน้อย), แดง (หมดแล้ว), เทา (ยังไม่มีข้อมูล)
- Popup เมื่อคลิกหมุด: รูปร้าน, ชื่อร้าน, ป้ายสถานะ, "อัปเดตเมื่อ X นาทีที่แล้ว", ระยะทางจากคุณ, ปุ่ม "อัปเดตสถานะ", ปุ่ม "นำทาง" (เปิด Google Maps directions ในแท็บใหม่), ลิงก์ "ดูรายละเอียดร้าน"
- แถบ Filter chips: ทั้งหมด / 🟢 มีหมูกรอบ / 🟡 เหลือน้อย / 🔴 หมดแล้ว / ⚪ ยังไม่มีข้อมูล (คงตัวกรองเดิม "ใกล้ฉัน" ไว้เป็น "ทั้งหมด")
- ช่องค้นหาชื่อร้านแบบเรียลไทม์ — พิมพ์แล้วแผนที่เลื่อน (flyTo) ไปที่ร้านที่ตรงที่สุดและเปิด popup ให้เอง
- รายการร้านด้านข้างยังอยู่เหมือนเดิม คลิกรายการแล้วแผนที่เลื่อนไปที่ร้านนั้น

## Modal อัปเดตสถานะ

ใช้กฎเดิมของระบบ (ยืนยันตำแหน่งจริงภายใน 100 เมตร):

1. กด "อัปเดตสถานะ" ใน popup → เปิด Dialog
2. Dialog ขอ/ตรวจตำแหน่ง GPS แล้วคำนวณระยะห่างจากร้าน
3. อยู่ในระยะ 100 ม. → เลือกสถานะ 4 แบบ ใส่หมายเหตุ (ไม่บังคับ) แล้วกดบันทึก → ข้อความ "ขอบคุณสำหรับข้อมูล!" / "รายงานของคุณถูกบันทึกแล้ว"
4. อยู่ไกลเกิน / ไม่อนุญาต GPS / ยังไม่เข้าสู่ระบบ → แสดงเหตุผลเป็นภาษาไทยและปิดปุ่มบันทึก พร้อมลิงก์ไปหน้ารายละเอียดร้าน
5. บันทึกสำเร็จแล้วรีเฟรชข้อมูลร้านใกล้ตัว ทำให้สีหมุดเปลี่ยนตามสถานะใหม่

การคำนวณสถานะยังทำที่ฝั่งเซิร์ฟเวอร์เหมือนเดิม หน้าเว็บเขียนได้แค่ตาราง reports

## รายละเอียดทางเทคนิค

- ติดตั้ง `leaflet`, `react-leaflet`, `@types/leaflet`
- Leaflet ใช้ `window`/`document` ตอน import จึงต้องโหลดแบบ client-only: สร้าง `src/components/map/MookrobMap.tsx` แล้วโหลดผ่าน `React.lazy` ใต้ `<ClientOnly>` ในหน้า `/map` (ห้าง import ตรงจากไฟล์ route) พร้อม skeleton ระหว่างโหลด
- `import "leaflet/dist/leaflet.css"` อยู่ในไฟล์คอมโพเนนต์ client-only
- เลี่ยงปัญหา default marker icon หายโดยใช้ `L.divIcon` ที่วาด SVG pin เองทั้งหมด (ไม่พึ่ง `marker-icon.png`) — ไฟล์ `src/components/map/markers.ts` เก็บฟังก์ชันสร้างไอคอนตามสถานะ โดยดึงสีจาก token `--status-*` ใน `src/styles.css`
- ใช้ `useMyLocation()` และ `useNearbyRestaurants()` เดิม ไม่แตะ data layer; ลบการใช้ `withMapCoords` และคอมโพเนนต์ `MapMarker.tsx` ที่ไม่ใช้แล้ว
- การเลื่อนแผนที่ทำผ่านคอมโพเนนต์เล็ก ๆ ที่เรียก `useMap()` (`flyTo`) และ `useRef` เก็บ marker เพื่อเปิด popup
- Modal ใช้ `Dialog` จาก shadcn, `useSubmitReport()` + `getPrecisePosition` ที่มีอยู่แล้ว, `toast` จาก sonner
- คง head meta ของ route เดิมไว้ และตรวจ responsive มือถือ/แท็บเล็ต/เดสก์ท็อป (ความสูงแผนที่ปรับตาม breakpoint เหมือนเดิม)
