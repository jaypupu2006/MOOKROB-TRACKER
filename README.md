# 🥓 MooKrob Tracker (เครื่องมือเช็กสถานะหมูกรอบ)

**MooKrob Tracker** คือเว็บแอปพลิเคชันสุดล้ำสำหรับคนรักหมูกรอบ! ช่วยให้คุณเช็กสถานะความพร้อมของหมูกรอบตามร้านค้าต่าง ๆ ในพื้นที่ใกล้ตัวคุณแบบเรียลไทม์ โดยอ้างอิงจากรายงานของผู้ใช้งานจริงที่อยู่ที่ร้าน ป้องกันปัญหาการเสียเวลาเดินทางไปแล้วพบว่าหมูกรอบหมดลงก่อน

---

## ✨ คุณสมบัติเด่น (Features)

1. **📍 ตรวจสอบสถานะหมูกรอบจริง (Real-time Status)**
   * **🟢 มีหมูกรอบ** (`available`)
   * **🟡 เหลือน้อย** (`low`)
   * **🔴 หมดแล้ว** (`out`)
   * **⚪ ยังไม่มีข้อมูล** (`unknown`)

2. **⚖️ ระบบคำนวณแบบถ่วงน้ำหนักฉันทามติ (Weighted Consensus)**
   * คำนวณสถานะร้านอาหารผ่านฟังก์ชันฝั่งฐานข้อมูล โดยอิงจากความสดใหม่ของข้อมูล (หมดอายุหลังจาก 3 ชั่วโมง), คะแนนความน่าเชื่อถือของผู้รายงาน และความถูกต้องของสัญญาณ GPS

3. **🗺️ แผนที่ร้านหมูกรอบใกล้ตัว (Interactive Map)**
   * ใช้ **Leaflet** ในการพิกัดตำแหน่งร้านค้าและระบุพิกัดนำทางไปยัง Google Maps
   * ค้นหาร้านค้าและคัดกรองตามรัศมีระยะทาง (1 กม. / 3 กม. / 5 กม.), ประเภทร้าน (ร้านหมูกรอบ, อาหารตามสั่ง, ก๋วยเตี๋ยว) และสถานะของหมูกรอบได้ทันที

4. **📌 ระบบรายงานพื้นที่จำกัด (Geofenced Reporting)**
   * ป้องกันสแปมข้อมูลด้วยการจำกัดให้ผู้ใช้รายงานสถานะได้เฉพาะเมื่อ**อยู่ใกล้ร้านอาหารในรัศมี 100 เมตร**เท่านั้น โดยตรวจจับพิกัดความแม่นยำสูงผ่าน GPS

5. **🏆 ระบบสะสมแต้มและเหรียญตรา (Gamification & Trust Score)**
   * ผู้ใช้เริ่มต้นจะมีคะแนนความน่าเชื่อถือเริ่มต้นที่ `10/100` คะแนนจะขยับขึ้นลงตามความถูกต้องของรายงาน
   * สะสมระดับเลเวลและปลดล็อกเหรียญตราผู้รายงาน:
     * 🌱 **ผู้รายงานใหม่** (`new`)
     * 🥓 **ผู้รายงานทั่วไป** (`regular`)
     * 🛡️ **ผู้รายงานที่น่าเชื่อถือ** (`trusted`)
     * 👑 **ผู้รายงานยอดเยี่ยม** (`elite`)

6. **🔔 ระบบร้านโปรดและการแจ้งเตือน (Watchlist & Notifications)**
   * กดติดตามร้านค้าเพื่อเปิดระบบเตือนเมื่อหมูกรอบเปลี่ยนสถานะโดยไม่จำเป็นต้องคอยกดเข้ามาเช็กบ่อยๆ

## 🛠️ เทคโนโลยีที่ใช้ (Tech Stack)

* **Frontend Framework**: [TanStack Start](https://tanstack.com/router/v1/docs/start/overview) (React 19)
* **Styling**: Tailwind CSS v4, Radix UI Primitives, Lucide React
* **Database & Auth**: [Supabase](https://supabase.com/)
* **Map Engine**: Leaflet & React Leaflet
* **State & Data Fetching**: TanStack Query (React Query)
* **Package Manager**: Bun / npm

## 🚀 การติดตั้งและรันโปรเจคในเครื่อง (Local Development)

### 1. ความต้องการก่อนติดตั้ง (Prerequisites)
* ติดตั้ง [Node.js](https://nodejs.org/) (เวอร์ชัน 18 ขึ้นไป) หรือ [Bun](https://bun.sh/)

### 2. โคลนโปรเจคและติดตั้ง Dependencies
```bash
# ติดตั้ง dependencies ด้วย Bun (แนะนำ)
bun install

# หรือใช้ npm
npm install
```

### 3. ตั้งค่าสภาพแวดล้อม (Environment Variables)
สร้างไฟล์ `.env` ในโฟลเดอร์ root ของโปรเจค และกำหนดค่าเชื่อมต่อของ Supabase:
```env
SUPABASE_URL="https://your-project-id.supabase.co"
SUPABASE_PUBLISHABLE_KEY="your-anon-key"
```

### 4. รันโปรเจคสำหรับพัฒนา (Run Dev)
```bash
# รันเซิร์ฟเวอร์ด้วย Bun
bun run dev

# หรือใช้ npm
npm run dev
```
เปิดบราวเซอร์ไปที่ [http://localhost:3000](http://localhost:3000)

### 5. คำสั่งอื่น ๆ ที่เป็นประโยชน์
* **Build โปรเจค**: `bun run build` หรือ `npm run build`
* **รัน Preview ตัวทดสอบ build**: `bun run preview` หรือ `npm run preview`
* **จัดระเบียบโค้ด**: `bun run format` หรือ `npm run format`

## 🗄️ โครงสร้างฐานข้อมูล (Database Schema)

ระบบใช้งานตารางบน Supabase ต่อไปนี้:
* **`restaurants`**: เก็บข้อมูลร้านอาหาร พิกัด (Latitude/Longitude), เวลาเปิด-ปิด, ราคาเฉลี่ย และคะแนนรีวิว
* **`restaurant_status`**: ผลคำนวณสถานะล่าสุดของหมูกรอบ คะแนนความมั่นใจ และจำนวนผู้รายงานล่าสุด
* **`reports`**: เก็บประวัติการรายงานสถานะ พิกัดของผู้ส่งขณะส่ง และบันทึกเพิ่มเติม
* **`users`**: โปรไฟล์ผู้ใช้งาน คะแนนความน่าเชื่อถือ จำนวนการส่งรายงาน
* **`watchlists`**: รายชื่อร้านโปรดที่ผู้ใช้เลือกติดตามพร้อมเปิดรับการแจ้งเตือน
* **`notifications`**: บันทึกรายการแจ้งเตือนเพื่อแสดงผลบนหน้าเว็บเมื่อร้านโปรดอัปเดตสถานะ
